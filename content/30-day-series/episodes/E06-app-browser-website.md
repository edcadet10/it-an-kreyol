# E06 — App, browser, ak website

## Learning objective

The learner can distinguish an installed application, a web browser application, and a website/service loaded through the browser.

## Audience problem

Saying “the internet is broken” can hide whether the problem is one app, one website, the browser, Wi‑Fi, or the wider connection.

## Draft beats

- **Hook draft:** “Chrome pa entènèt la—Chrome se youn nan pòt ou sèvi pou wè Web la.”
- An app is software installed or delivered for a task.
- A browser is an app that requests and displays web resources.
- A website/service runs on servers and is reached through a URL; many services also have dedicated apps.
- This distinction gives troubleshooting choices: try another site, browser, app, or network.

## Visual

Layered cards: device → browser app → URL/request → website server. Use `example.com`, not a look-alike domain.

## Knowledge check / CTA

“Safari se yon website oswa yon browser?”

## Evidence

- [MDN — How the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works)

## Review flags

- Do not imply every app merely wraps a website.
- Keep “internet” and “web” distinction for E12; do not overload this episode.
