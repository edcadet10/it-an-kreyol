# E04 — Kisa yon operating system fè?

## Learning objective

The learner can explain that an operating system manages device resources and provides the environment in which applications interact with hardware.

## Audience problem

Beginners recognize Android, iOS, Windows, macOS, or Linux names but may not know why the OS matters when installing apps, managing files, or troubleshooting.

## Draft beats

- **Hook draft:** “Anvan TikTok ouvri, gen yon lòt sistèm k ap òganize telefòn nan.”
- Name Android/iOS and Windows/macOS/Linux as examples, without market-share claims.
- Explain resource management: CPU time, memory, storage/files, input/output, networking, and permissions.
- Apps request services from the OS rather than controlling every hardware detail directly.
- Connect OS/version to compatibility and support.

## Visual

Layer diagram: user → app → operating system → hardware.

## Knowledge check / CTA

“Android se hardware, app, oswa operating system?”

## Evidence

- [IBM — What is an operating system?](https://www.ibm.com/think/topics/operating-systems)

## Review flags

- Avoid saying every computing device uses a general-purpose OS in exactly the same way.
- Recheck platform names immediately before recording.
