# E25 — Poukisa updates enpòtan

## Learning objective

The learner can explain that updates often correct known defects/security weaknesses and can enable verified automatic updates where appropriate.

## Audience problem

Update fatigue, limited data/storage, and fear of change lead people to postpone patches indefinitely or install fake “update” prompts from unsafe sources.

## Draft beats

- **Hook draft:** “Lè yo dekouvri yon twou nan yon kadna dijital, update la ka pote reparasyon an.”
- Updates can include security fixes, bug fixes, compatibility changes, and features; they are not all identical.
- Use the device/app's official update mechanism or trusted store, not an unexpected popup/link.
- Back up important data and ensure adequate power/connectivity for significant OS updates.
- Automatic updates reduce delay where they fit the user's device/data constraints.

## Visual

Known flaw → vendor fix → verified update channel. Use mock UI or exact current official UI only.

## Knowledge check / CTA

“Yon popup o aza di `Update now` epi mande w telechaje yon fichye. Ki premye bagay pou fè? Ale nan mekanis ofisyèl app/aparèy la.”

## Evidence

- [CISA — Secure Our World](https://www.cisa.gov/secure-our-world)
- Exact official vendor update instructions for the demonstrated OS/app are required before `Ready`.

## Review flags

- Recheck CISA current/archived status and vendor guidance.
- Do not promise every update is trouble-free or advise bypassing support limitations.
