# E05 — File, folder, ak extension

## Learning objective

The learner can use folders to organize files and recognize a filename extension as a clue to file type, without treating an extension as proof that a file is safe.

## Audience problem

People lose downloads, confuse a file with its containing folder, or rename an extension and expect the file format to change.

## Draft beats

- **Hook draft:** “Ou telechaje yon dokiman, men kounye a ou pa ka jwenn li. Ann òganize l.”
- File: a named unit of stored content; folder/directory: a container used to organize items.
- Show a fictional path such as `Documents/IT-an-Kreyol/E05-script.txt`.
- Explain `.txt`, `.jpg`, and `.pdf` as type clues; changing letters after the dot does not convert content.
- Warn that a familiar-looking name/extension does not make a download trustworthy.

## Visual

Sanitized file manager with invented filenames; show moving one file into a clearly named folder and revealing extensions.

## Knowledge check / CTA

“Nan `foto.jpg`, ki pati ki ede sistèm nan rekonèt kalite fichye a?”

## Evidence

- [Microsoft Support — File Explorer in Windows](https://support.microsoft.com/en-us/windows/experience/fileexplorer/file-explorer-in-windows)

## Review flags

- Steps are Windows-specific if demonstrated; label the version and avoid implying Android/iOS/macOS paths match.
- Privacy review the entire screen, including recent files and account names.
