# E12 — Entènèt la pa menm ak Web la

## Learning objective

The learner can explain that the internet is a network of interconnected networks and the Web is one service that uses it.

## Audience problem

Treating the Web, a browser, Wi‑Fi, and the internet as the same thing makes troubleshooting and later networking lessons difficult.

## Draft beats

- **Hook draft:** “Entènèt la ak Web la travay ansanm, men yo pa menm bagay.”
- Internet: underlying connected networks moving data using protocols.
- Web: pages/apps/resources requested with web technologies through clients such as browsers.
- Give other internet uses at a high level, such as messaging or email, without overexplaining protocols.
- Connect back to E06: a browser is an application used to access web resources.

## Visual

Large road/network labeled `Entènèt`; one delivery vehicle/service labeled `Web`. State that the analogy is simplified.

## Knowledge check / CTA

“Si yon mesaj app mache men yon website pa louvri, èske sa deja pwouve tout entènèt la koupe?”

## Review flags

- Keep the simplified distinction technically defensible; avoid defining internet solely as cables.
